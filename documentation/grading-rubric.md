# Code Grading Rubric

1. ## _Code Quality (30 Points)_

- Readability (5 Points)
  - Code is well organized & easy to follow
  - Code uses clear and descriptive variable names

- Efficiency (5 Points)
  - Code uses optimal data structures & algorithms
  - Code minimizes unnecessary computations
  - Code uses caching or memorization where appropriate

- Correctness (10 Points)
  - Code produces the correct output for all test cases
  - Code handles edge cases and errors gracefully
  - Code follow best practices for error handling

- Style (10 Points)
  - Code adheres to a consistent coding style
  - Code uses appropriate indentation & whitespace
  - Code avoids unnecessary complexity

2. ## _Functionality (40 Points)_

- Requirements (20 Points)
  - Code meets all requirements specified in technical and non-technical requirements document (10 points)
  - Code implements all required features (5 points)
  - Code handles all required input & output formats (5 points)

- Additional Features (10 Points)
  - Code implements additional features beyond the requirements (5 points)
  - Code demonstrates creativity & innovation (3 points)
  - Code provides additional value to user (2 points)

- User Experience (10 Points)
  - Code provides a good user experience (5 points)
  - Code is intuitive & easy to use (3 points)
  - Code provides clear & helpful feedback (2 points)

3. ## _Documentation (30 Points)_

- Code Comments (15 Points)
  - Code includes clear & descriptive comments (10 points)
  - Comments explain the purpose & functionality of the code (3 points)
  - Comments are well-formatted & easy to read (2 points)

- README File (10 Points)
  - README file is included & well-written (5 points)
  - README file clearly explains how to run the code/program/app (3 points)
  - README file provides additional information about the code/program/app (2 points)

- Code Organization (5 Points)
  - Code is well-organized & easy to navigate (3 points)
  - Code uses appropriate directories & files (1 point)
  - Code uses clear & descriptive file names (1 point)
